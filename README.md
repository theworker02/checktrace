# checktrace

Check timestamps and trace durations for scripts and CI receipts.

**Site:** https://theworker02.github.io/checktrace/

## Install / run

```bash
git clone https://github.com/theworker02/checktrace.git
cd checktrace
node src/cli.js
node --test
```
